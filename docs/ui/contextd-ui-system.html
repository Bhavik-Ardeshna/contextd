Theming & honesty rules

  • · Components reference shadcn CSS vars — never hardcode dark/light surfaces.
  • · Brand color used only for actions, selection, and the hot graph path.
  • · Status colors mean what they mean: green healthy, amber pending, blue running, red failing, purple inferred/LLM, gray empty.
  • · Mono for IDs, hashes, queries, schema fields, timestamps. Sans for prose.
  • · Implementation status is visible: V1PreviewRoadmap.
  • · Empty states are operational with one primary CTA — no marketing fluff.
  • · Tables are central; row hover + sticky header + mono IDs + right-aligned counts.
  • · No card-in-card. Use panels, bands, tables, split panes, drawers.
